How the instrument's code works

A map of every function and variable in script.js. Pick a walkthrough to follow one action step by step, or choose Explore and click any box to see what it connects to.

The big idea: the program has two halves that never call each other. On the left, events (your pointer and keyboard) run handlers that only change the state. On the right, two loops keep running on their own: they read the state and turn it into pictures and sound. The state in the middle is the only thing connecting them.
